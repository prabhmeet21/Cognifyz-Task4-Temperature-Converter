# 🌡️ Temperature Converter

A simple and user-friendly **console-based Temperature Converter** developed in Python as part of the **Cognifyz Technologies Software Development Internship – Level 2, Task 4**.

The application allows users to convert temperatures between **Celsius and Fahrenheit** through an interactive menu.

---

## 📌 Project Overview

The Temperature Converter is a Python console application that performs temperature conversions between Celsius and Fahrenheit.

The application provides a simple menu-driven interface where users can:

- Convert Celsius to Fahrenheit
- Convert Fahrenheit to Celsius
- Exit the application
- Handle invalid inputs using exception handling

---

## 🎯 Objective

The objective of this task is to develop a temperature converter that converts temperatures between **Fahrenheit and Celsius** while practicing Python functions, user input, conditional statements, loops, and exception handling.

**⚙️ How the Application Works**

When the application starts, it displays a menu with three options:

==========================================
          TEMPERATURE CONVERTER
==========================================
1. Celsius to Fahrenheit
2. Fahrenheit to Celsius
3. Exit
==========================================

**1️⃣ Celsius to Fahrenheit**
The application uses the formula:

Fahrenheit = (Celsius × 9/5) + 32
**Example:**
Enter your choice (1-3): 1
Enter temperature in Celsius: 100

100.00°C = 212.00°F

**2️⃣ Fahrenheit to Celsius**
The application uses the formula:

Celsius = (Fahrenheit - 32) × 5/9
**Example:**
Enter your choice (1-3): 2
Enter temperature in Fahrenheit: 212

212.00°F = 100.00°C
**
3️⃣ Exit**
The user can select option 3 to safely exit the application
